# Phase 0: Move the Vial core to Python 3.13 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The existing Qt app and its full test suite run on Python 3.13 with current dependencies.

**Architecture:** No new architecture. Update dependency pins, fix the code and tests that break on 3.13, stop the GUI tests from reading the developer's real Vial settings, and point the helper scripts and CI at 3.13.

**Tech Stack:** Python 3.13, PyQt5 5.15.11, PyInstaller 6.22.3, hidapi 0.15.0 (PyPI), pytest 9 / pytest-qt 4.5, fbs 0.9.0 (installed with --no-deps until phase 6).

**Spec:** `docs/superpowers/specs/2026-10-15-vial-web-ui-design.md`

## Ground rules (read before every task)

1. **Never touch the owner's keyboard.** Nothing you run may enumerate or open real HID devices.
   - Never run `vial_web.py` without `--fake`.
   - Never start the Qt app (`src/main/python/main.py`) unless `hid` is replaced by the no-devices stub from the last task of the phase 0 plan.
   - Tests use simulated devices only.
2. **Shell:** Git Bash on Windows; commands are written for it. On Linux/macOS replace `.venv/Scripts/python.exe` with `.venv/bin/python`.
3. **Python:** the repo venv `.venv` (Python 3.13). Tests always run from `src/main/python`, because the code uses top-level imports (`from protocol.keyboard_comm import ...`):

   ```bash
   cd src/main/python
   QT_QPA_PLATFORM=offscreen ../../../.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider test
   ```

   `QT_QPA_PLATFORM=offscreen` keeps Qt windows from appearing on screen.
4. **Line endings:** the repo uses CRLF on Windows checkouts. Edit with tools that keep existing line endings.
5. **Commits:** one commit per task, on branch `web-ui`. End every commit message with the trailer the session tells you to use.

## Background

- **Python 3.6 era pins.** The repo targets Python 3.6 (PyQt5 5.9, PyInstaller 3.4, `fbs`). An investigation on 2026-10-15 showed that the code runs on 3.13 with:
  - newer dependency versions;
  - one invalid string escape (`keymap/polish.py:21`);
  - float arguments to `QPoint` in two tests.
- **`fbs` pin conflict.** `fbs` 0.9.0 pins `PyInstaller==3.4`, which has no Python 3.13 build. `fbs` goes in its own requirements file and is installed with `--no-deps`. `pip check` will report that conflict; that is expected, and `fbs freeze` works with PyInstaller 6.
- **The hidapi fork is no longer needed.** `vial-kb/cython-hidapi` is upstream hidapi 0.10.1 plus a Cython pin for 3.6, so PyPI `hidapi` replaces it.
- **The GUI tests leak the developer's settings.** `MainWindow` uses `QSettings("Vial", "Vial")`, the same store as the developer's installed Vial. A saved `maximized=true` made 4 GUI tests fail on Windows. Task 3 isolates the settings.

            compile(path.read_text(encoding="utf-8"), str(path), "exec")

    assert problems == []
