# Project rules

- **New features go in the README.** When a feature is added or changed, update `README.md` in the same piece of
  work: describe it under "What it does" (what it does for the user, in plain words, every sentence true for the code
  and the firmware), and update the "Status" table when a phase is done.
- **The README is updated whenever a phase or stage is done.** Before a phase or stage counts as finished (merged to
  `main`), `README.md` matches it: the "Status" table row, "What it does" for what it added or changed, and any
  section it makes untrue (how to run, build, test, options, files).
